# Segurança dos dados - rascunho

Use este conteúdo como base no formulário de Segurança dos dados da Play Store.

## Dados coletados

- Nome.
- E-mail.
- Telefone opcional.
- Fotos enviadas pelo usuário, como perfil, participantes e comprovantes.
- Dados financeiros inseridos pelo usuário: despesas, grupos, participantes, valores, categorias e observações.

## Finalidade

- Funcionalidade do app.
- Gerenciamento de conta.
- Cálculo de divisão de despesas.
- Geração de relatórios e exportações solicitadas pelo usuário.

## Compartilhamento

O app não vende dados pessoais. Resumos só são compartilhados com WhatsApp/outros aplicativos quando o usuário aciona essa função.

## Segurança

Senhas são armazenadas com hash. O tráfego usa HTTPS. Cada usuário acessa seu próprio conjunto de dados.

## Exclusão de dados

Antes da publicação aberta, recomenda-se criar uma tela ou processo de solicitação para exclusão total da conta e dos dados.
